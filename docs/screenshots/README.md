# ESP32-style screenshot collection

Every PNG is 480×320, captured with the corresponding example's S3 renderer
settings and with the runtime performance overlay hidden. Both field parities
use the same frozen pose. These are native renders, not LCD photographs or
high-resolution desktop renders. See [capture instructions](../../tools/screenshots/README.md)
and the [pose/configuration manifest](manifest.json).

One `<example-directory>.png` image per project appears in the repository gallery.
These images are also available for Jet's documentation.

Captures retain the underlying examples' artwork rights. See the repository licence and asset provenance notes.
