# Car assets

`Nascar Intel - Separate Windows.obj`, its matching `.mtl`, and `outrun.png`
were supplied by Michael from his **Nascar Intel Edition** project. The originals
are retained unchanged here. They include the CubeCoders racing livery.
No separate asset licence was supplied; the repository's code licence does not
establish a licence for these model and livery files or their derived textures.

`tools/prepare_assets.py` embeds the OBJ/MTL source text and converts the image to
`livery-256.png`: vertically flipped for OBJ UV convention, resized to 256x256,
then quantised to 256 colours without dithering. The generated firmware contains
8-bit indices and an RGB565 palette. Model coordinates/normals are converted at
runtime in `Workshop::loadCar`, keeping the atlas islands intact.

`workshop-environment.png` is a procedural 128x64 panorama generated by the same
script for the demo. Its cyan/magenta ribs and ceiling strips approximate the room.
It is sampled as direct RGB565 with nearest sampling. The generator also creates
the title/caption bitmap labels and the checked-in `Assets.hpp`/`Labels.hpp` files.
