# Original generated artwork

The arcade test card and three cube tiles are generated by
`../tools/prepare_assets.py` and supplied under the examples repository's MIT
licence. No downloaded game artwork is used. The card is 256x128 RGB565
(64 KiB); the three 32x32 RGB565 cube tiles add 6 KiB. All remain immutable in
flash. Labels are separate RGB565 sprites generated with a local monospace font.
The font file is not distributed; use `--font` to choose a replacement.
