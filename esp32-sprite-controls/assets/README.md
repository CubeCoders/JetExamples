# Air Mail artwork

`courier.png` is original procedural pixel artwork created for this example,
covered by the examples repository MIT licence. It depicts a red propeller mail
plane with a cream stripe, glazed cockpit and a fixed wheel. Black is transparent.
The generated RGB565 texture is 64x32 (4 KiB), displayed at 2x scale.

The generator also rasterizes immutable captions using the selected local font.
The font itself is not distributed. Use `--font` to regenerate with another font.
