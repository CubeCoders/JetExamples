# Texture Lab assets

All image patterns and foliage geometry are generated by the project's
`tools/prepare_assets.py`; no downloaded art or external model is needed.
They are covered by the example code's MIT licence.

- `address-tile.png`: 64x64 RGB image, stored as 8 KiB RGB565. Its distinct edge
  colours make clamp behaviour visible and the arrow shows UV orientation.
- `keyed-foliage.png`: 96x128 image, stored as 24 KiB RGB565. Magenta is the key.
  The opaque and keyed texture descriptors share the same immutable pixels.
- `indexed-lava.png`: preview of the 64x64 index field at palette offset zero.
  Firmware stores 4 KiB of indices and 64 RGB565 colours (128 bytes).
- A 32x32 RGB565 checker backdrop consumes 2 KiB and is generated into the header.

The texture pixels total 39,040 bytes. The separate immutable label bitmaps are
also generated and embedded in flash. Their font can be selected with `--font`.
Neither textures nor labels require runtime image decoding.
